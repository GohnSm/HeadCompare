# HeadCompare

## English Version

**HeadCompare** is a web-based tool for designing and comparing laser head trapezoid configurations. It allows you to edit, visualize, simplify, and manage multiple heads in an interactive canvas and table interface.

### Features

- Visual editor for laser head trapezoids.  
- Multiple heads support with color and transparency customization.  
- Interactive table with input fields for trapezoid parameters (`b1`, `b2`, `h`).  
- Add, delete, and duplicate trapezoids.  
- Move between fields using arrow keys.  
- Auto-simplify heads to a maximum of 15 trapezoids.  
- Export and import parameters in `.json`.  
- Placeholder export/import for `.chc` files (TubesT format, currently not fully supported).  
- Display trapezoid dimensions directly on the canvas.  
- Scale and move entire heads on canvas.  
- Export to SVG/DXF formats (implementation placeholder).

### How to Use

1. Open `index.html` in a modern browser.  
2. Use the side panel to add new heads or edit existing ones.  
3. Edit trapezoid parameters in the table; use arrow keys for navigation.  
4. Click "Auto-simplify" to create a simplified version of the head.  
5. Export or import parameters using `.json` files.  
6. Visualize changes directly on the canvas.  

### Planned Features

- Fully compatible `.chc` export for TubesT.  
- Improved SVG/DXF export.

## Русская версия

**HeadCompare** — это веб-инструмент для проектирования и сравнения конфигураций трапеций лазерной головки. Позволяет редактировать, визуализировать, упрощать и управлять несколькими головками с помощью интерактивного интерфейса таблицы и канваса.

### Возможности

- Визуальный редактор трапеций головки лазера.  
- Поддержка нескольких головок с возможностью настройки цвета и прозрачности.  
- Интерактивная таблица для ввода параметров трапеций (`b1`, `b2`, `h`).  
- Добавление, удаление и дублирование трапеций.  
- Перемещение между полями с помощью стрелок.  
- Авто-упрощение до максимум 15 трапеций.  
- Импорт и экспорт параметров в `.json`.  
- Заготовка для экспорта/импорта файлов `.chc` (формат TubesT, пока не полностью поддерживается).  
- Отображение размеров трапеций прямо на канвасе.  
- Масштабирование и перемещение всей головки на канвасе.  
- Экспорт в форматы SVG/DXF (заготовка).

### Как использовать

1. Откройте `index.html` в современном браузере.  
2. Используйте боковую панель для добавления новых головок или редактирования существующих.  
3. Редактируйте параметры трапеций в таблице; навигация стрелками.  
4. Нажмите "Авто-упрощение" для создания упрощённой версии головки.  
5. Экспортируйте или импортируйте параметры через файлы `.json`.  
6. Изменения отображаются сразу на канвасе.  

### Планируемые возможности

- Полноценный экспорт `.chc` для TubesT.  
- Улучшенный экспорт в SVG/DXF.
